## A6. `handdrawn-workflow-tutorial`：手绘流程教程演示

### 可直接调用的完整提示词

```text
暖白色手绘白板教程演示风格。画面不是静态 PPT，也不是真实录屏，而是跟随中文口播把一个工作流逐步搭建出来：上方或右上有一个黑色手绘浏览器窗口代表原始素材，细黑引线把内容拆成 2 到 4 张浅青信息卡；随后用一条手绘流程线和圆形节点把它们组织成步骤；一叠白色步骤纸从画面边缘滑入，沿着被画出的粗黑箭头送进一个简化的工具/聊天窗口，窗口内的响应气泡依次出现；最后只用一个胭脂红胶囊标签锁定“确认/执行/结果”。画布为暖白纸面，线条为近黑墨线，组件有轻微不规则的手绘轮廓和小号图钉/胶带提示。动画以路径绘制、轻拍落位、节点依次点亮、纸张连续传递和结果短块浮现为主；每个动作服务于一句口播，前一状态保留为后一状态的视觉证据。
```

负面提示词：

```text
不要做成真实屏幕录制，不要密集工具栏、长篇代码、小字号文字或无目的鼠标移动；不要做成杂志拼贴、满屏撕纸和照片；不要做成彩色儿童插画；不要有大幅弹跳、旋转飞入、镜头抖动、粒子、霓虹、全屏闪白或无意义转场；不要把每个步骤切成互不相干的新页面；不要同时出现多个红色重点。
```

### 内容结构与视觉令牌

默认六段为：来源/问题（0–15%）→ 提取（15–30%）→ 结构化（30–50%）→ 可复制指令（50–68%）→ 执行（68–88%）→ 结果锁定（88–100%）。短视频可压缩为“来源 → 拆解 → 执行 → 结果”；长教程可以复用“步骤纸 → 工具窗口 → 结果卡”，但同屏不能堆叠多个活跃步骤。

| 项目 | 规定 |
|---|---|
| 画布/线条 | 暖白 `#FBFAF4`，极弱纸纹与暖暗角；近黑墨线 `#151515`，等比 2–4px、圆端点 |
| 强调 | 胭脂红 `#D81E45` 只用于当前结论、确认、执行、CTA；淡青 `#DDF4F5` 表示被提取的信息 |
| 语义组件 | 浏览器框=来源；信息卡=提取；圆节点=步骤；红胶囊=确认；叠纸=可复制指令；粗箭头=传递；工具窗=执行目的地 |
| 一句一动 | 新名词先出现对象；解释关系才画连线；说“下一步/送进/确认”才触发移动 |

### 组件边界与动作

| 组件 | 使用边界 |
|---|---|
| `sketch-browser` | 暖白底黑手绘框、3 个浏览器点、简化缩略图；1 个主窗口+1 个辅助窗口 |
| `info-card` | 淡青/白卡、微图标、正文 ≤8 字；同屏最多 4 张 |
| `step-rail` | 单条黑线+白圆节点；3–6 步，当前节点最清楚 |
| `step-paper` | 1–3 张轻倾斜白纸，用于 3–5 条可复制步骤 |
| `ink-arrow` | 粗黑可微弯箭头；同时最多 2 条活跃箭头 |
| `action-pill` | 胭脂红白字胶囊；同屏只允许 1 个主标签 |
| `tool-window` | 简化工具壳；同屏 1 个；`response-bubble` 最多 3 条 |
| `pin-sticker` | 胶带/图钉微装饰；同屏最多 4 个 |

动作时序：引线/箭头 SVG 画线 280–650ms，箭头端晚 60–100ms；卡片/标签/纸张从 16–36px 轻拍落位 260–420ms；节点点亮 180–300ms；纸张抽取 450–650ms（后层晚 70–120ms）；纸张沿贝塞尔路径送入工具 500–800ms；气泡按结论块 180–320ms/条出现。元素需稳定停留 0.35–0.8 秒。每 0.4–1.2 秒发生小状态变化，每 3–5 秒完成一轮逻辑转换。

### 结构提示词片段

```text
拆解来源：手绘浏览器窗口居上，窗口下写“提取框架，不复制素材”。从窗口底部画 3 条细黑引线，连接浅青信息卡；卡片按顺序轻拍落位，当前要点有一个小图钉提示。

形成步骤：暖白画面出现手写标题“拆成 N 个步骤”，下方红色胶囊写“N 个步骤”。中下部从左向右画黑色流程线，白色圆节点逐个生成并写简短动作词；当前节点最清楚，完成节点降对比度。

送进工具：左下步骤纸滑入，纸上只保留 3–5 条操作；粗手绘箭头通往右侧简化聊天/工具窗口。纸张沿箭头缩小进入窗口前，连续出现 2–3 条短响应气泡，最后出现红色确认标签。
```
