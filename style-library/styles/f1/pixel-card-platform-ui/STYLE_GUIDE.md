### 视觉令牌与组件

| 项目 | 规则 |
|---|---|
| 背景 | `#FFF4D8` / `#FFF7E8`，叠加 `rgba(119,88,32,.14)` 点阵纸纹；不是纯白 |
| 主色 | 深蓝 `#0647B8` / `#003F9E`；黑描边 `#111111` |
| 功能色 | 奖励黄 `#F7C600`，成功绿 `#26B84A`，提醒红 `#E4484C`，未完成灰 `#C9C9C9` |
| 形状 | 主卡 3–5px 黑描边，4–8px 像素偏移阴影，硬矩形，禁止柔大圆角 |
| 装饰占比 | 问号砖块、金币、水管、星星等仅占画面 5–15%，且不得出现真实版权角色/商标 |

组件：头像信息卡（蓝像素头像、等级、星级、积分）；标题图标卡；单/三列数据卡；左蓝栏签到卡与七日方格；任务清单卡；四行功能入口；深蓝横向提示卡；按钮组、标签/徽章、通知栈；星星站在砖块平台上的奖励/空状态卡。

动作：卡片以 1–2 帧阶梯缩放轻拍进入；星星从左到右填充；数字确定性逐级增长；签到格依次勾选；选中行短促蓝闪；按钮下压 3–4px；星星/金币仅短促闪动。不能使用现代弹性 bounce 或随机数值。
