## A1. `editorial-data-report`：编辑型数据简报风

### 可直接调用的完整提示词

```text
冷灰白的编辑型数据简报动效，不是 PPT，也不是科技 HUD。每一页都像同一本研究报告：顶部有小号章节标签、细横线和页码；正文从一条短红线启动，再出现左对齐的大号黑色标题，只有核心判断中的一个短语用信号红。中部只摆放一套证据结构，例如模块拼接的大数字、三张分类卡、横向排行榜、方块规模集群，或带红色左边线的证据注释框。数据按阅读顺序逐层建立，最后在下方出现一句黑红混排的结论。画面保持大面积留白，颜色严格限于黑、红、灰，并局部使用黄或蓝表示类别。场景转场先淡回浅灰白纸面，再由下一页红线和标题建立。
```

负面提示词：

```text
不要深色背景，不要透明黑玻璃 HUD，不要霓虹发光，不要赛博网格，不要 3D 金属物，不要人物口播主体，不要弹跳、旋转、全屏横移、粒子，不要满屏小字图表，不要所有元素同时进入，不要无来源的伪数据。
```

### 视觉令牌与版式

| 项目 | 规定 |
|---|---|
| 画布 | `#F4F7F4` 冷灰白；预留大面积负空间 |
| 文字 | `#0C0D0D` 黑色；短语级重点用 `#D9274D` 信号红 |
| 类别色 | `#FFD526` 黄仅标记一个单元/引用短语；`#347FB8` 蓝仅作第三类别；非重点为 `#BFC4C2` |
| 固定框架 | 顶部 9% 留给章节标签、细横线、页码；所有页面共用左对齐网格 |
| 信息层级 | 红短线 → 标题 → 证据 → 来源/解释 → 一句结论；一页只讲一个论点和一组证据 |

### 组件与动效配方

| 组件 | 使用场景 | 动效 |
|---|---|---|
| Report Chrome | 章节标签、日期/主题、页码、顶部分隔线 | 首次建立后保持稳定，是跨页锚点 |
| 模块数字 Hero | 版本、日期、数量、发布节点 | 黑色方块按数字笔画组 0.7–1.1 秒组成；再出现说明标题 |
| Claim Headline | 每个新论点 | 红线 220ms 从左画出；60ms 后标题 `y:18→0`、透明度进入 |
| 分类卡 | 三方比较、模型阵容、分类定义 | 白卡+彩色顶帽，按阅读顺序 90ms 错开入场 |
| 横向排名条 | benchmark、成本/性能比较 | 条形从左向右 650ms 生长；数值在条形落位后淡入 |
| 证据注释 | 纠偏、引用、限定条件 | 先白框和红左边线，再出文字，最后黄笔划过短语 |
| 规模集群 | `1 → 4 → 16` 等规模关系 | 黑单格、红色 2×2、蓝色 4×4 逐组组成 |
| 结论 | 页面记忆点 | 所有证据完成后再出现；结论短语用红色 |
| White-out 转场 | 报告页切换 | 旧内容 360ms 淡至底色，停 100–140ms，再从红线开始新页；绝不整页横移 |

推荐时序：兄弟元素错开 60–120ms；标题 420ms，正文 300ms，卡片 360ms，结论 400ms。只用透明度、短距离位移、确定性宽度增长和线条绘制；不使用弹性、旋转、粒子和永久动效。

### 可粘贴的 `DESIGN.md` 块

```markdown
### 视觉方向
- 风格库：`editorial-data-report`
- 背景：冷灰白报告纸面，顶部保留章节、细分隔线与页码。
- 核心视觉：红色短线启动标题；黑红混排论点；模块数字、数据条、分类卡、证据注释框与一句结论。
- 色彩：`#F4F7F4` 背景、`#0C0D0D` 主文字、`#D9274D` 论点与重点、`#FFD526` 局部标记、`#347FB8` 第三分类、`#BFC4C2` 非重点数据。
- 动效：先红线、后标题、再证据，最后落结论；条形图由左向右生长；场景之间白底淡退。
- 不要做：HUD、深色玻璃、赛博霓虹、弹跳卡片、全屏滑页、密集仪表盘。
```
