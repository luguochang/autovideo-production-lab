| 项目 | 规则 |
|---|---|
| 背景 | `#05070D` / `#090D14` 暗色电影空间；玻璃面板 `rgba(6,10,18,.72)`，细边 `rgba(120,180,255,.28)` |

| 横版 | 左上论点；中心/偏右讲解者或主体；左能力面板，右场景面板；底部双语字幕与来源 |
| 竖版 | 顶部标签，中上主体，中下最多三组堆叠数据卡，底部大字幕，侧边窄进度标记 |
| 数据优先 | 左主图/关系图，右人物或辅助面板；每 2–4 秒只保留一个焦点对象 |

可用组件：左右论点面板、3–5 项市场份额排行、2×2/3×1 场景卡、层级推广链、单句证据条、前后 Delta 卡、横/竖时间线、最多 7 节点关系图、数据来源标、固定双语字幕条、焦点光标/扫描线、最后的论点锁定页。

动作：面板从最近边缘滑入 16–40px 并在 160–280ms 内淡入；条形 400–800ms 生长；数值从 0 确定性增长；焦点边框从 1.00 到 1.025 后停住；连线分段画出。场景切换保持人物/背景稳定，替换数据层。每个图表只回答一个口播主张，示意数据必须标“示意”，真实数据应在面板底部给出来源。
