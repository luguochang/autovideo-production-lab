## Provenance Rules

- `spec-only` means the rules can guide reconstruction, but no missing example, image, font, code, or asset may be implied to exist.
- Official registry code can be installed through HyperFrames, but every bundled photo, logo, font, sound, or third-party texture still needs an asset-level license receipt before publication.
- Community code without a detectable license is research evidence only.
- Brand assets from the student kit are not reusable even though its code is MIT.
- Save source URL, commit/version, local path, SPDX/license status, and any attribution requirement in the project `AssetManifest`.
