## 5. 复现命令

单个横屏工程检查：

```powershell
cd E:\project\study\codex\autoVideo\experiments\E10-style-probes\variants-landscape\A-handdrawn-board-landscape
npx.cmd --yes hyperframes@0.7.59 check --snapshots --at 0,1.2,3,5.6,7.24 --json
npx.cmd --yes hyperframes@0.7.59 keyframes --json
```

渲染示例：

```powershell
npx.cmd --yes hyperframes@0.7.59 render --quality standard --workers 2 --crf 22 --output "..\..\renders\A-handdrawn-board-landscape.mp4"
```

重建六条审片海报并复核媒体：

```powershell
cd E:\project\study\codex\autoVideo\experiments\E10-style-probes
node .\scripts\build-review-posters.mjs
node .\scripts\verify-probes.mjs
```

启动审片页：

```powershell
npx.cmd --yes http-server . -p 3301 -c-1
```

## 6. 前置条件与剩余风险

- Node.js 22+、FFmpeg/ffprobe 和可用 Chromium 是检查与渲染前提。
- A/B 目前依赖 Windows 本机中文字体；C 的 Inter 已进入 HyperFrames 字体缓存。正式发布系统应把获准商用的中文字体和拉丁字体冻结进项目，避免跨机字形与换行变化。
- 当前 QA 证明结构、渲染、媒体和黑场安全，不代表风格已经获得用户批准。
- 选定横屏主风格后，应再用连续 20-30 秒口播验证多信息点节奏，之后才扩展完整稿。

## 7. 选择建议

- 最接近“老师在一张画板上讲解”：A。
- 最适合案例、截图、证据与观点拆解：B。
- 最适合 RAG、模型、架构和数据密集技术内容：C。
- 推荐组合仍是 A 作为基础空间语法，只按需要借 B 的证据纸片或 C 的数据条；不要把三套完整视觉系统混成一套。
