# 连续讲解模板与工作台操作手册

适用模板：`modern-ip-host-explainer + continuous-shell-compiler@1.7.0`。

## 1. 两个预览入口

- 轻量审片播放器：只负责从头播放、暂停、拖动和试听，优先用它看连续性与配音。
- HyperFrames Studio：负责时间线、对象选择和最终确认。Studio 是编辑面，不是最终 MP4。

正式高质量 MP4 只在人工审片通过后生成。模板探针和旧成片不会互相覆盖。

## 2. 在工作台修改画面

1. 打开 AutoVideo 生产工作台并选择项目。
2. 在流程图中点击“HyperFrames 全片制作”或“Studio 最终预览”。
3. 在右侧选择“画面微调”。
4. 选择目标层级：
   - 场景：改章节标题或人物姿态。
   - 节拍：改某一句口播对应的主画面。
   - 画面对象：按稳定 ID 精确覆盖一个视觉状态。
5. 填写修改原因并保存。工作台会保留历史版本，并把全片编译、结构 QA、终审、渲染和交付标记为“需重算”。
6. 点击“重新生成”，从全片制作开始重跑失效的下游步骤。配音、字幕文字和时间轴不会因此重做。

## 3. 主画面文字怎么填

不要粘贴完整口播。完整 NarrationLock 只在底部字幕显示。

主画面填写 1-4 个关键词，用全角竖线分隔：

```text
理解｜判断｜维护｜负责
```

第一个词是主视觉，其余词是辅助信息。保存后它会记录为 `manual-keywords`，不会修改口播稿。

## 4. 动效版式怎么选

| 版式 | 适用内容 |
|---|---|
| 关键词聚焦 | 单一概念、短结论，默认优先 |
| 风险 / 结论提示 | 报错、失败、风险、警告 |
| 并列清单 | 三项左右的真实并列项 |
| 真实流程 / 关系 | 明确的先后、从 A 到 B、步骤关系 |
| 前后对比 | 两个状态、误区与正确理解 |
| 章节收束 | 章节结论或全片结尾 |

没有真实顺序关系时不要选择“流程”。人物默认固定在左侧 `600x730` 区域，只在语义节点交叉淡化姿态。

## 5. 流程图布局怎么修改

“流程图与素材计划”的正式产物是 `autovideo-graph-layout/v1`。允许修改每个节点的 `x / y / width / height`，但不得修改 `graphId`、节点 ID、边 ID 或边的端点；这些语义来自 Graph IR。

保存并批准布局后，从“HyperFrames 全片制作”重新生成。工作台会把布局物化为 `plan/graph-layout.json`，在 `production-manifest.json` 中绑定 SHA，并把实际使用情况写入 composition source map 和 build receipt。没有有效布局绑定时，编译器才使用保守的确定性排版。

当前入口是合同校验后的 JSON 编辑；React Flow 拖拽式图解编辑器仍未完成。

## 6. 配音怎么处理

- 固定预设：CosyVoice 中文女，`speed 1.03`，`seed 7`。
- 模板在开头增加 `0.35s` 呼吸时间，字幕和动效同步后移。
- 如果某个 cue 仍显得抢速，只重做该音频段，并重新生成 alignment、字幕、视觉计划、动效和渲染。
- 未完成人工完整试听、术语确认和段落拼接检查时，只能标记为内部审片，不能公开发布。

## 7. 什么时候算完成

以下项目全部完成后，才是可交付成片：

1. NarrationLock、配音和时间对齐已锁定。
2. 主画面无整页闪切，人物区域不漂移，字幕每次只显示一条。
3. HyperFrames check 通过，关键边界帧已人工查看。
4. 工作台中的配音听审与 Studio 全片审片由人确认。
5. 生成新文件名的高质量 MP4，并通过 FFmpeg、字幕、视觉、事实和权利 QA。
6. 交付包、素材来源、许可证和构建哈希齐全。
