## 2. 已验证可保留的动画方案

本轮没有使用整页 PPT 式硬切，而是将背景、人物、字幕和内容画板拆成常驻图层。已验证以下规则可以继续使用：

1. 背景、人物和字幕层不随场景卸载。
2. 相邻内容场景保持约 18-24 帧重叠，旧内容尚未完全退出时新内容已经进入。
3. 普通元素只做约 14-40px 的短距离位移，不从画面外长距离飞入。
4. 元素使用 ease-out 进入、ease-in 退出；重点词才使用轻微弹簧落定。
5. 透明度、位移、缩放和模糊使用不同的持续时间，避免所有属性同步变化形成 PPT 感。
6. 关键词按真实词级时间点触发，不按平均字数盲播。
7. 同一时刻只让少量元素运动，其余内容保持稳定，给观众阅读时间。
8. 所有动画状态由全局帧纯计算，支持 Remotion 并行、乱序渲染。

已完成的检查：

- TypeScript 类型检查通过。
- MP4 视频轨为恒定 30fps。
- `nb_frames` 与 `nb_read_frames` 均为 1165，没有缺帧。
- 对四组转场进行了 10fps 连续抽帧检查，没有空白换页。
- Remotion Studio 可以打开、播放和拖动 `FlowMotionDemo`。

## 3. 当前明确问题

### 3.1 视觉内容生成不合格

用户反馈：动画效果暂时可以，但生成出来的视频内容和画面质量不行。

当前样片的视觉元素主要由代码绘制的文字、标签、箭头和占位人物组成，存在以下问题：

- 画面仍然偏程序员原型，缺少可直接发布的视觉质感。
- 人物、插图、场景素材和真实内容配图均为缺失状态。
- 内容表达过度依赖通用标签，不能充分表现口播中的具体含义。
- 五个场景的坐标和动画时间仍然硬编码，不是可复用的自动生成流水线。
- 当前只有文本分镜，没有建立“口播语义 -> 图片需求 -> 图片资产 -> 画面布局”的完整链路。
- 参考视频中的截图巡航、手绘文字、图标和差异化视觉素材尚未覆盖。

### 3.2 后续视觉方案改用中转站的 image2

后续正式视觉资产优先通过用户提供的中转站调用 `image2` 生成，不再只依赖 CSS 占位图形。

待用户提供或确认：

- 中转站 Base URL
- 鉴权方式
- `image2` 的准确模型名称
- 请求与响应格式
- 是否支持参考图、透明背景、指定尺寸、固定 seed 或角色一致性参数
- 并发限制、单次费用和失败重试规则

建议只通过本地 `.env` 保存敏感配置，不能把 API Key 写入源码、JSON、日志或本文档。建议配置名：

```text
IMAGE_API_BASE_URL=
IMAGE_API_KEY=
IMAGE_MODEL=image2
```

拟定图片生成流程：

```text
已审稿口播
-> 章节和语义节拍
-> 图片需求清单
-> image2 批量生成候选图
-> 一致性与可用性检查
-> asset-manifest.json
-> Remotion 使用 Img 图层合成
-> 抽帧 QA
```

图片不能逐镜头无约束生成。需要先固定人物设定、色板、构图规范、负面约束和参考图，再生成姿势、图标、背景、插图及截图替代素材。每项资产应保存提示词、模型、尺寸、版本和来源，便于重做与追踪成本。

### 3.3 当前声音过于生硬

用户反馈：当前声音机械、停顿和情绪不自然，需要作为独立问题处理。

当前问题可能来自：

- Edge TTS 默认音色不适合该类观点型讲解。
- 整段文本直接合成，停顿主要依赖标点，缺少语义级节奏设计。
- 英文术语、数字和中英文混读没有发音词典。
- 语速基本恒定，没有强调、转折、疑问和总结的变化。
- 没有做响度统一、均衡、压缩、齿音控制及呼吸间隔处理。

后续需要进行配音 A/B 测试，至少比较：

1. 更自然的云端中文 TTS。
2. CosyVoice、GPT-SoVITS 或用户授权音色。
3. 中转站若提供语音模型，也加入同文案对比。

配音生成前应先把文稿转换为“可朗读脚本”，加入段落停顿、转折停顿、重音、英文术语读法和数字读法。动画时间线必须继续以最终音频的真实边界为准，不能为了画面强行拉伸语音。

## 4. 下一阶段实施顺序

1. 获取中转站和 `image2` 的接口说明，在本地完成最小请求验证。
2. 从参考稿选择 45-60 秒，先生成一套正式图片资产，不直接处理全片。
3. 将当前硬编码画面升级为 `scene -> cues -> assets -> operations` 数据结构。
4. 接入图片缓存、提示词记录、失败重试和资产清单。
5. 用同一段文字生成 2-3 个配音版本，先确认音色和节奏。
6. 重新渲染高保真样片，同时评审视觉内容、动画和声音。
7. 样片通过后，再扩展到完整 3:50 视频；50 分钟内容必须按 3-5 分钟章节生成和渲染。

## 5. 下一版验收标准

### 动画

- 不出现空白换页、突然跳位或线性匀速滑动。
- 关键词与发音同步，场景交接保持分层重叠。
- 动画为内容服务，不依靠持续漂浮、频繁缩放或无意义特效制造动态。

### 视觉

- 画面不能只由通用文字卡片组成。
- 每个主论点至少有一种与内容直接相关的图片、图标、结构图或截图表达。
- 同一人物和同系列素材保持风格、比例、光线和色彩一致。
- 自动布局不得出现重叠、裁切、字号过小或大面积无意义空白。

### 声音

- 中文口语自然，段落和转折有可感知但不过长的停顿。
- `AI`、`Codex`、`Claude Code`、`Agent` 等术语发音稳定。
- 重点句有重音和语速变化，不全程保持同一机械节奏。
- 最终音频响度一致，无明显爆音、齿音或句尾突断。

## 6. 当前决策

- 保留本轮已经验证的 Remotion 分层重叠动画方案。
- 不以当前 CSS 占位画面作为正式视觉模板。
- 下一版视觉资产优先采用用户中转站的 `image2`。
- 配音质量必须单独选型和 A/B 验证。
- 在视觉资产与配音方案确认前，不开始生成完整长视频。
