# 标准化视频工作流探索与实施计划

> 建立日期：2026-07-16  
> 状态：第一轮源码调研、Edge TTS 和三套完整竖屏候选已完成；等待风格确认与可编辑通用流水线实施  
> 本文是项目总入口。具体实验结果应写入《探索执行日志》，不要只保留在聊天记录中。

## 1. 最终目标

构建一套长期可复用、可编辑、可局部重做的知识讲解视频生产系统：用户提供已经确认的口播稿，系统在不改写口播的前提下，自动完成语义切分、视觉规划、素材生成、连续画板动画、配音/字幕对齐、预览编辑、质量检查和 MP4 渲染。

目标体验不是逐页播放 PPT，而是老师在同一张大画板上持续讲解：旧内容可以保留、缩小、移动和重组；新内容在空白区域展开；镜头按知识结构平移和缩放；文字、流程图、图片和标注均保持连续对象身份。

```text
已审稿口播稿
  -> 确定性切分和朗读脚本
  -> 语义节拍与视觉意图
  -> 素材需求和画板对象
  -> 连续对象操作与相机时间线
  -> 可视化预览和人工修改
  -> TTS、字幕、BGM 与真实时间戳
  -> 程序化渲染、自动 QA、MP4
```

## 2. 不可妥协的产品原则

1. **口播归用户所有**：用户确认的正文是唯一事实来源。模型不能改写口播，只能生成视觉元数据。
2. **对象连续而非页面连续**：视频核心是常驻画板、对象状态和相机关键帧，不是 `scene -> next page`。
3. **中间产物可编辑**：文稿、素材、对象、时间线和字幕均保存为结构化文件，不能只存在于生成代码中。
4. **优先组装成熟项目**：每一层先检索、运行和比较开源组件；只有缺少合适组件时才开发薄适配层。
5. **局部修改、局部重算**：改一句口播、换一张图或调整一个动画时，不应重新生成整条视频。
6. **确定性渲染**：同一份工程数据应可重复输出一致视频，不能依赖 GUI 鼠标自动化作为主链路。
7. **来源可追踪**：模型、提示词、素材来源、许可证、生成时间、费用和版本都写入 manifest。
8. **先样片后长片**：每项能力先在 30-45 秒基准稿上验证，再扩展到 3-5 分钟章节。

## 3. 建议的系统边界

系统由“规划层、资产层、画板层、时间层、编辑层、渲染层、质量层”组成。各层通过稳定的中间格式连接，可以替换实现。

```text
Narration IR
  -> Visual Plan IR
  -> Asset Manifest
  -> Canvas Document
  -> Timeline Operations
  -> Render Project
  -> QA Report
```

### 3.1 建议目录

```text
projects/<video-id>/
  source/
    narration.approved.md
    pronunciation.json
  plan/
    narration.json
    visual-plan.json
    evidence.json
  assets/
    asset-manifest.json

  audio/
    narration/
    music/
  captions/
    captions.json
    captions.srt
  previews/
  renders/
  qa/
    report.json
    contact-sheets/
```

### 3.2 核心对象操作

第一版统一支持：`add`、`write`、`move`、`scale`、`highlight`、`connect`、`replace`、`remove`、`camera`、`pause`。对象必须有稳定 `id`，才能跨口播片段保留和重排。

## 4. 第一轮调研后的开源积木选择

源码、许可证、维护状态和实际渲染入口已经完成第一轮核验，详细证据见《端到端开源视频工作流调研》。下面是本机实验的当前优先级，不代表未经验证的最终承诺。

| 能力层 | 当前选择 | 本机重点验证 |
|---|---|---|
| 连续动画/渲染 | **HyperFrames 0.7.59 主线**；Revideo 备选 | 单 composition、常驻对象、相机、音频时间线、Windows 无头渲染 |
| 可视化人工编辑 | **HyperFrames Studio** | DOM 文字/位置/图片、时间线、关键帧、关闭重开后的持久化 |
| HTML/SVG 内容 | HyperFrames DOM/SVG + Mermaid/D2/Graphviz/ELK.js | 稳定元素 ID、中文排版、路径动画、重排 |
| 可编辑 PPT 支线 | PPT Master；必要时 Presenton | 只作为独立 PPTX/页面交付，不进入视频主时间线 |
| 图标和插图 | Iconify、Lucide、开源插图库、`image2` | 许可证、风格统一、透明背景、缓存和角色一致性 |
| 资产生成 | 用户中转站 `image2`、可选本地模型 | 参考图、固定角色、尺寸、透明背景、seed、费用和重试 |
| TTS/时间戳 | **Edge TTS 先跑通**；其他音色后续 A/B | 中文术语、停顿、词边界、授权和吞吐 |
| 音视频处理 | FFmpeg/ffprobe | 编码、响度、缓存、黑帧、静音、字幕和轨道检查 |
| 工作流/QA 参考 | OpenMontage、ResearchStudio、MoneyPrinterTurbo | 只借鉴 Schema、审批、TTS/字幕和 QA，不引入不匹配的整套运行时 |

当前不再把 Motion Canvas + 自研编辑器或 tldraw/Excalidraw 双向适配作为首轮主线。只有 HyperFrames Studio 的本机实验暴露不可接受缺口时，才启动 Revideo 或独立画板编辑器实验。

截至 2026-07-16，本机对照实验已经完成：HyperFrames 全链通过；Motion Canvas 缺少受支持的 headless CLI；Revideo 0.11.0 在当前 Windows/Chrome 环境两次无头导航失败；Remotion 作为成熟保底保留。最终实施取舍见《[架构决策与下一阶段实施基线](./02-架构决策与下一阶段实施基线.md)》和《[连续画板与渲染引擎调研](./research/连续画板与渲染引擎调研.md)》。

## 5. HTML/PPT、SVG 和图片的定位

### 5.1 HTML/PPT

HTML/CSS 适合文字、标签、表格、代码和信息卡组件，也便于可视化编辑。PPT/Slidev 可作为内容导入、人工审阅或额外交付格式，但不能成为视频主时间线，否则容易退回逐页切换。

### 5.2 SVG

流程图、架构图、箭头、图标和手绘标注优先保存为 SVG。生成工具负责布局，动画层读取节点和路径，为节点出现、路径描边、强调、缩放和重排添加时间线。需要验证生成 SVG 是否保留稳定元素 ID；若没有，应在转换阶段注入 ID。

### 5.3 图片与 `image2`

图片用于人物、具体物体、场景、难以用图形表达的概念和用户提供的定制素材。静态图片仍可通过裁切、蒙版、局部标注、相机巡航和前后景分层获得动画感。图片生成必须先形成资产清单，不按镜头无约束随机生成。

## 6. 可编辑性的目标形态

编辑器第一版直接使用 HyperFrames Studio，不先开发完整剪辑软件。需要实测并保留的能力是：

- 播放、暂停和按时间定位。
- 画板平移、缩放和对象选择。
- 修改屏幕文字和主题色。
- 拖动、缩放、隐藏和替换对象。
- 调整对象出现/消失时间和动画预设。
- 替换用户图片或重新生成单个资产。
- 预览当前 5-15 秒区间。
- 将修改持久化回 HTML/GSAP，并保存结构化生成源与用户覆盖项。

自动生成层使用稳定对象 ID 和显式 GSAP tween；人工修改后生成 `overrides.user.json` 或等价 patch，后续局部重算不得覆盖 `data-user-locked="true"` 的对象。只有 Studio 无法满足上述最低能力时，才单独评估 tldraw/Excalidraw。

## 7. 探索实验

主线能力先在 30-45 秒已审稿窗口验证，再按风险扩展到完整口播。E08 实际偏离了这条顺序，先输出三套约 275 秒全文，再派生 35.6 秒预览；它补充了长时间线证据，但增加了无效渲染成本。后续恢复短样片先行，这也不替代 Studio 编辑和通用 IR 的验收。

### E01 HyperFrames 连续画板闭环

使用 30-45 秒已审稿口播，在一个 HyperFrames root composition 中实现 8-12 个常驻对象、相机移动和真实 Edge TTS 对齐。完成 Studio 人工修改、关闭重开、重新渲染和自动 QA。若出现无法绕过的编辑或渲染限制，再用同稿制作 Revideo 对照样片。

### E02 HTML/SVG 内容组件

测试文字卡、代码块、对比表、Mermaid/D2/Graphviz 流程图。验证生成 SVG 的元素 ID、中文排版、路径动画和重排效果。

### E03 Studio 编辑与局部覆盖

验证 Studio 中改文字、拖位置、替换图片、调整关键帧和 easing；关闭重开后确认源 HTML/GSAP 已持久化。随后只重生成一个未锁定对象，确认不会覆盖其他人工修改。

### E04 图片资产链

主链跑通后再验证 `image2` 最小请求、参考图、透明背景、一致角色、多姿势、失败重试、缓存和 `asset-manifest.json`；第一条闭环样片可先用 SVG、图标和已授权本地图片。

### E05 口播与配音

第一条闭环只使用 Edge TTS，建立术语词典和停顿标记；动画只使用最终音频的真实边界。其他音色和引擎在主链稳定后再做 A/B，不作为当前前置条件。

当前结果：E05 已完成 `zh-CN-XiaoxiaoNeural / 1.05` 独立探测；E08 已用 `zh-CN-YunxiNeural / 1.08` 完成三套完整视频。原文一致性、词/句边界、字幕和音频解码均已验证。

### E06 局部修改

分别修改一句口播、一个标签、一张图片和一个动画，记录需要重算的文件、耗时和是否影响未修改区间。

### E07 自动 QA

构造黑帧、文字溢出、对象遮挡、音频缺失和字幕错位样本，验证检测脚本能否稳定报错。

## 8. 评分与选型方法

每项方案使用 1-5 分，并保留证据链接、版本、命令、截图和成片。

| 维度 | 权重 |
|---|---:|
| 连续画板动画质量 | 25% |
| 数据驱动和自动化 | 20% |
| 用户可编辑性 | 15% |
| 内容表达能力 | 15% |
| 渲染稳定性和性能 | 10% |
| 接入与维护成本 | 10% |
| 许可证和商用风险 | 5% |

任何存在明显黑闪、对象跳位、无法固定口播、不能保存可编辑中间数据或许可证不可接受的方案直接淘汰，不用综合分掩盖硬伤。

## 9. 分阶段实施

### 阶段 A：环境和基准冻结

- 归档当前原型，不再把它当正式架构继续堆功能。
- 固定基准口播、参考视频、输出规格和验收表。
- 记录 Node、浏览器、FFmpeg、GPU、字体和代理环境。

### 阶段 B：开源组件探索

- 已完成首轮官方仓库、许可证、活跃度、文档和渲染入口核验。
- 上游仓库放在 `vendor/`，实验代码放 `experiments/`，不直接修改上游。
- 先完成 HyperFrames 主线 E01-E03；只在实测失败时扩大到 Revideo/独立编辑器。

### 阶段 C：资产与声音

- E05 Edge TTS 已完成；E04 图片和人物资产链在主风格确认后实施。
- 建立素材 manifest、缓存和敏感配置规范。

### 阶段 D：最小完整流水线

- 实现 IR schema、适配器和 CLI 编排。
- 从已审稿口播生成 30-45 秒可编辑工程和成片。
- 完成局部修改与 QA。

### 阶段 E：编辑器和产品化

- 提供画板编辑、时间调整、素材替换和区间预览。
- 加入项目版本、任务状态、失败恢复和批量生成。

## 10. 本机操作和记录约定

- 所有真实密钥只放 `.env` 或用户级环境变量，不写入源码、文档和日志。
- 第三方仓库放入 `vendor/<project>`；不要直接修改上游，适配代码放本项目。
- 实验放入 `experiments/E##-name/`，每个实验必须有 README、复现命令、版本和结论。
- 外部下载素材放 `references/`，注明用途和版权状态，不直接混入发布资产。
- 每次安装、启动、失败、修复和淘汰都追加到《探索执行日志》。
- 每个重要结论必须有本机运行结果，不以 README 宣传或 Star 数代替验证。

## 11. 第一轮探索完成标准

第一轮不是交付完整产品，而是交付有证据的主线闭环：

- 一条 30-45 秒 HyperFrames 单 composition 连续画板成片；只有主线遇到硬限制时才补 Revideo 对照。
- HyperFrames Studio 的文字、位置、图片、时间线和关键帧保存/恢复实验。
- 至少三种流程图 SVG 的生成与动画实验。
- Edge TTS 的真实音频/字幕对齐；`image2` 和其他 TTS 延后验证，不阻塞主链。
- 推荐架构、备选架构、淘汰原因和许可证清单。
- 一份可运行的 30-45 秒最小完整流水线。

截至 2026-07-16，连续画板成片、Edge TTS、三类流程图和成片级 QA 已有本机证据；Studio 真实 UI 编辑同步与通用最小流水线仍未完成，因此第一轮工程闭环不能标记为全部完成。

## 12. 当前已知结论

- 已审稿口播模式是默认生产模式。
- 整页 beat/Sequence 替换会产生 PPT 感，不作为最终画板模型。
- 常驻背景、人物、字幕和对象身份是连续感的基础。
- Remotion 已验证可稳定编码和做绝对时间动画，但现有 beat/Sequence 分页模型不继续扩展。
- 第一轮源码调研推荐 HyperFrames 单 composition + Studio + 薄编排层；Revideo 是渲染备选。
- 不再优先自研 Motion Canvas 编辑链，也不先接 tldraw/Excalidraw 双向适配器。
- PPT Master、Presenton、OpenMontage、ResearchStudio 和 MoneyPrinterTurbo 只复用与目标匹配的独立能力或设计经验。
- 正式视觉不能只靠 CSS 占位标签，必须接入 SVG、图标、图片和用户素材。
- E08 已证明完整长口播可渲染；在主风格确认前不继续增加模板数量，也不输出 1080x1920 发布母版。
