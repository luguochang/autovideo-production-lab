# 连续画板样片验证

## 2026-07-15 技术样片

- Composition：`CanvasStyleDemo`
- 输出：`renders/canvas-style-demo.mp4`
- 规格：1280x720、30fps、31.07 秒、5,491,060 字节。
- 视频轨 H.264，音频轨 AAC 48kHz 双声道。
- FFmpeg 全片黑帧检测：`BLACK_FRAMES=NONE`。

## 动画结构

1. 米色画板、讲解员和字幕常驻。
2. `音频接入 / VAD / ASR / LLM / TTS` 标签逐个写入。
3. 第一组内容整体缩小并移动到左上角，保持可见。
4. 输入流程在画板中央展开。
5. 相机向右平移，旧流程从左侧边缘保留上下文。
6. 输出流程、打断机制和总结在画板右侧逐步出现。

整个视频只有一个长期存在的世界画板，不使用分页 `Sequence` 切换。

## 风格确认项

- 画板：当前为浅米色横线纸，可改纯色、网格纸或白板。
- 人物：当前为代码绘制占位讲解员；正式版需要原创或用户授权 PNG，并准备 3-5 个姿势。
- 标签：当前为蓝、绿、珊瑚红纸片风格。
- 镜头：当前使用缓慢平移和缩放，可调整速度与移动幅度。
- 字幕：当前为底部深色整句字幕。

风格确认后，下一阶段把硬编码对象改为 `objects + timeline operations` JSON，并接入已审稿口播模式。
