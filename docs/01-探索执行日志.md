## 2026-07-16 / E02-SVG / 可编辑画板与 SVG 组件验证

### 本机结果

- `npm.cmd run verify` 全部通过。
- ELK 保留节点/边 ID 和路由；Graphviz 保留显式 SVG ID；Fabric 自定义 ID 可 JSON 往返。
- Mermaid 必须注入 canonical `data-object-id`；Mermaid-to-Excalidraw 可生成可编辑元素，但新转换的文本 ID 不稳定，导出 SVG 也不保留语义 DOM ID。
- 结论：Graph IR + ELK.js 是默认图布局；Excalidraw 只做图表子编辑器；动画独立保存在 canonical timeline，不能依赖导出 SVG 或编辑器私有 JSON。

### 输出

- `docs/research/可编辑画板与SVG组件调研.md`
- `experiments/E02-editable-canvas/output/verification.json`

## 2026-07-16 / E09 / HyperFrames 风格库与 Codex 项目配置

### 输入

- `demo/f1/HF_风格与动效库_分享包搭建说明 (1).md`
- `demo/f1/HyperFrames视频工作流分享手册.md`

- `nateherkai/hyperframes-student-kit`、Orkas VideoStudio 等社区项目。

### 核验结论

- F1 两份文档提供了真实可用的方法和 7 套完整风格规范，但不是可运行分享包；其引用的 `style-libraries/`、`hyperframe-library/`、`workflow-kit/`、示例和参考图片均未随当前工作区提供。
- HyperFrames 官方本身已提供 8 个示例、109 个 block、25 个 component、13 套 frame preset、8 套命名风格和 37 条 motion rule。之前直接自写 E08 生成器，没有充分使用这些现成积木。
- 社区中最强的可复用来源是 MIT 的 `hyperframes-student-kit`，包含 12 个成品工程、运动哲学和短视频 Skill；AIS 品牌素材明确不允许复用。
- Orkas VideoStudio 的 MIT `plan.json`/delivery guard 值得后续做 IR 对照；无许可证的社区 Skill 只借鉴思路，不复制代码和资产。

### 本机操作

- 稀疏克隆 `vendor/hyperframes-student-kit`，只保留许可证、工作流/动效文档、Skills 和 `may-shorts-19` 竖屏工程代码，不下载品牌素材与成片。
- 新增根 `AGENTS.md`，让后续 Codex 在本项目中自动执行“先查官方库、先任务单、先短探针、后全文”的工作流。
- 独立 Codex 前向测试确认能自动发现并正确执行该项目规则；风格未批准时不会直接进入全文渲染。
- 新增 `style-library/registry.json`、风格/动效入口、来源台账、任务/评审模板和 style-selection Schema。
- `npm.cmd run styles:sync` 生成 7 套 F1 快照、8 套官方风格、13 套 frame preset、142 个 registry 项、15 个 scene blueprint 和 37 条 motion rule 索引。
- `npm.cmd run styles:validate` 通过 81 项检查。

### 决策

- 当前采用项目级 `AGENTS.md + style-library`，已足够让 Codex 在本工作区稳定读取规则。
- 暂不把这套规则装成全局 Codex Skill。只有 2-3 套风格经过用户成片验收后，再用 `skill-creator` 提炼为 `$CODEX_HOME/skills/autovideo-hyperframes-workflow`，避免把未验证审美传播到所有项目。
- 下一轮不再渲染三条全文做选型；固定同一 3-8 秒口播窗口，先做手绘教程、杂志证据和编辑数据三个短探针。

详细记录见《[HyperFrames 经验、风格库与 Codex 接入](./04-HyperFrames经验、风格库与Codex接入.md)》。
