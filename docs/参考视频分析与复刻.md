# 参考视频分析与复刻

## 参考样本

- 抖音视频 ID：`7650094288546372465`
- 公开分享元数据：约 234.82 秒，原始横屏 1920x1080；下载版本为 1280x720、30fps。
- 本地仅保留为样式分析参考，不作为生成视频的发布素材。

## 视觉特征

- 16:9 蓝灰色纯色背景，不是竖屏信息卡。
- 顶部常驻栏目标签，白色标题，薄荷绿重点词，浅红分类标签。
- 每 4-8 秒切换一个知识点，常见版式为关键词标签、横向流程、三栏对比和波形过渡。
- 动画以淡入、缩放、逐项出现为主，没有复杂三维镜头。
- 底部使用整句白色字幕，内容与旁白一一对应。
- 内容生产本质是“配音驱动的动态课件”，适合确定性程序渲染。

第二个 RAG 参考样本为 1152x720、约 137.09 秒。它进一步确认背景、顶部标题和字幕层持续存在，只对局部文字、人物贴图、箭头和标签做替换动画。

## 可用开源方案

1. Remotion：最适合固定品牌模板、JSON 驱动、批量渲染。本项目已采用。
2. HyperFrames `faceless-explainer`：适合 Agent 自动生成 HTML 信息图视频，已克隆到 `vendor/hyperframes`，后续可做质量对比。
3. Motion Canvas：适合更复杂的流程和代码动画，但模板开发成本更高。
4. pyJianYingDraft：可生成剪映草稿供人工终审，但不建议作为无人值守渲染主链。

## 一键生成

配置 `.env` 后执行：

```powershell
npm.cmd run pipeline:reference -- "文稿.md"
npm.cmd run pipeline:script -- "已审稿口播稿.md"
```

流水线会生成 20-28 个视觉节拍、逐段 Edge TTS、按真实音频时长排版，并输出 `renders/reference-style.mp4`。

其中 `pipeline:script` 不改写口播，适合用户先完成文字审稿；这是后续默认推荐模式。
