# 部署与流水线

## 当前架构

当前工程不是 HyperFrames 的启动副本，而是一个独立的 Remotion 项目。Remotion、React 和 Chrome Headless Shell 均由 npm 安装，因此即使没有克隆 GitHub 仓库也能启动和渲染。

```text
Markdown / PDF 文本
  -> 兼容 OpenAI 的 Chat Completions API
  -> content/storyboard.generated.json
  -> Edge TTS（逐场景音频与词级时间戳）
  -> Remotion 1080x1920 动画、字幕与音频
  -> renders/demo.mp4
```

## 配置

复制 `.env.example` 为 `.env`，填写模型服务配置。`.env` 已加入 `.gitignore`，禁止提交真实密钥。

## 命令

```powershell
npm.cmd install
npm.cmd run pipeline -- "资料文件.md"
npm.cmd run pipeline:reference -- "资料文件.md"
npm.cmd run generate:storyboard -- "资料文件.md"
npm.cmd run generate:tts
npm.cmd run render
npm.cmd run studio -- --port=3100
```

## 前置条件

- Node.js 22+（当前为 24.18.0）
- 能访问 npm、模型接口、Microsoft Edge Read Aloud 服务
- 模型服务 Base URL、API Key 和模型名
- 输入资料必须是有权处理的内容

PowerPoint 和系统级 FFmpeg 不是当前链路的必需项。Remotion 使用自己的渲染与编码依赖。

`pipeline` 会依次执行分镜生成、Edge TTS 和 MP4 渲染。真实密钥只应保存在本机 `.env` 或进程环境变量中。

`pipeline:reference` 输出与参考抖音视频接近的 1280x720 横屏动态课件；`pipeline` 保留原来的 1080x1920 竖屏模板。
