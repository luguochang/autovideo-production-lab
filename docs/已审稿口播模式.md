# 已审稿口播模式

## 原则

口播内容由用户最终确认，系统不负责改写观点或措辞。系统只做三件事：

1. 按中文标点和 58 字上限确定性切分口播。
2. 让模型为每个固定片段选择版式、屏幕标题、关键词和流程节点。
3. 使用原始片段生成 TTS、时间线和视频。

模型响应中不包含最终口播字段。程序在模型返回后重新绑定原始片段，避免模型偷偷改稿。

## 稿件格式

建议使用纯 Markdown：

```markdown
# 视频标题

第一段最终口播。这里写你确认过的原文。

第二段最终口播。技术术语和数字也以这里为准。
```

标题行不参与口播。正文中的句号、问号、感叹号和分号用于切分视觉节拍。

## 一键生成

```powershell
npm.cmd run pipeline:script -- "已审稿口播稿.md"
```

输出为 `renders/reference-style.mp4`。

## 黑闪修复

旧版在每个场景结束时将整个场景透明度降到 0，透明画布编码后表现为黑色闪烁。新版采用单一常驻蓝灰背景和常驻栏目标题，只替换局部文字、标签、箭头和插图；场景边界不再对整屏执行淡出。
