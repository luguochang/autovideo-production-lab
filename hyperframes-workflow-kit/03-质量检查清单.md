# 质量检查清单

## 结构与语义

- [ ] NarrationLock 哈希、口播范围和音频一致。
- [ ] 每个信息点有对应画面动作，没有无意义动态死区。
- [ ] 屏幕摘要类型和来源已标注。
- [ ] 结尾形成可读的累计状态。

## HyperFrames 与视觉

- [ ] `hyperframes check` 通过。
- [ ] 时间线可 seek、确定且无无限动画。
- [ ] 比例、安全区、中文断行、对比度和小屏可读性通过。
- [ ] 按语义时刻抽帧检查，而非只看固定间隔截图。

## 媒体与来源

- [ ] 音视频时长、解码、黑帧、响度和编码通过。
- [ ] 素材无缺失，AssetManifest 的来源和许可完整。
- [ ] 用户文档中未实际提供的 F1 示例或素材没有被宣称为已拥有。
