# 画面导演规则

1. 先锁定口播原文及 SHA-256，形成不可变的 `NarrationLock`。
2. 每个口播信息点必须对应可解释的可见变化，并记录原文范围。
3. 屏幕文字必须标为 `exact-source`、`approved-summary` 或 `generated-summary`。
4. 先定义每段静态终帧、信息层级和对象交接，再定义动画。
5. 风格只能从明确候选中选择：一个基础风格，最多两个有具体职责的组件家族。
6. 风格未决定时，对同一口播窗口制作静帧和 3-8 秒探针，不制作多个完整视频。
7. 优先复用官方 frame preset、example、registry item、blueprint 和 motion rule；自定义代码必须说明缺口。
