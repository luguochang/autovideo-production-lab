# 视频制作规则

1. 每条视频位于 `projects/<project-id>/`，不得直接写入共享风格库或其他实验目录。
2. composition 使用单一暂停、可 seek 的时间线；媒体播放交给 HyperFrames。
3. 禁止 `Math.random()`、墙钟时间、无限循环和关键在线素材。
4. 旧对象在仍有语义作用时交接到下一段，不用无意义清屏替代连续叙事。
5. 素材必须写入项目 `AssetManifest`，包含来源、版本或提交、许可和用途。
6. 用户批准 `VIDEO_TASK.md` 与 `STYLE_REVIEW.md` 后才能完整制作。
7. 使用 `hyperframes check`，不得使用已废弃的 `inspect`。
