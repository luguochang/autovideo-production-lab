# 十五章稳定画板与动效决策

状态：`revised-awaiting-narration-lock`  
基础风格：`modern-ip-host-explainer@1.0.0`  
画幅：`1920x1080 / 16:9 / 30fps`  
画布：`light-apricot / #F2DFC7`  
时长：`audio-driven`（机械稿曾估算约 19.4 分钟；推荐候选不设硬上限，正式 WAV 为准）

## 全局决策

- 主持人全片固定在 `host.left`，内容固定在 `content.right`，字幕固定在底部轨。
- 只使用同一人物；姿态按语义少量切换，不把换人物当作转场。
- 每章一个稳定画板，章内 3-6 个语义节点渐进构建；只在第 0-14 节边界更换画板。
- 每个画板先展示本章会用到的完整空间，再逐项高亮、连线、展开或收束；不依赖频繁切图承载信息。
- 所有进入过的元素必须明确退出或复位，禁止透明历史帧残留、重复人物和半透明叠影。
- 每章组合 2-4 条确定性原子规则；所有位置预计算、单一暂停时间线、可寻帧、无随机、无无限循环。
- 动画多样性来自信息关系不同，不使用装饰性旋转、粒子、连续缩放或 PPT 翻页。

## 节奏与防重叠约束

- 章内采用“完整空间建立 -> 当前节点聚焦 -> 关系构建 -> 终态停留”，每次只允许一个主焦点变化。
- 同一时刻最多 3 个活跃内容节点；新节点进入前，旧节点降级为稳定背景或明确退出。
- 所有人物姿态和内容卡使用互斥时间窗；禁止两张人物图交叉透明叠加。
- 章节终态至少停留一个可读周期，转场前先清理临时连线、提示光和中间态。
- QA 必须抽查章节中点、转场前后和任意重叠高风险帧；发现残影先修时序，不交给人工评审兜底。

## 屏幕文字策略

- 底部字幕：冻结口播的 `exact-source`。
- 大标题和节点：`generated-summary`，每个标题不超过 16 个汉字，每个状态最多 3 个活跃节点。
- “选型 / 落地 / 指标 / 提升方向”只作为屏幕导航短标签；旁白使用章节专属的口语过渡，不朗读栏目名。
- 论文编号、精确参数和实现类名从 `review/narration-editorial-report.json#screenOnlyTechnicalNotes` 读取，只作为小号来源脚注或技术标签，绝不混入旁白和精确字幕。
- 产品名与参数：只在对应章的辅助标签出现，不作为无来源的效果主张。
- 所有辅助文字保留来源类型，不能被误读为旁白原句。

## 审核结论

该方案保留首条样片已验证的角色、画布、字幕和稳定坐标，把来源稿第 0-14 节映射为十五块稳定画板。它不以五分钟为目标，也不通过频繁换页制造“丰富感”；变化来自每章不同的信息结构，并通过互斥时间窗和终态清理避免重叠、叠影与重复人物。
