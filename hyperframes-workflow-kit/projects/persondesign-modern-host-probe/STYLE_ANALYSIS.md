# 参考图风格分析

- Reference image: `input/style-reference.png`
- Analysis status: `completed`

## Approved Findings

- The supplied warm brown/brick-red host needs a clean complementary field, not a blue technology background.
- `light-apricot` is the approved default because it keeps the host warm while forest-green text preserves modern contrast.
- `warm-peach` is the approved alternate for people, lifestyle and light-knowledge topics.
- Caption `surface`, normal text and emphasis colors follow the selected palette; they are not a fixed pure-white overlay.
- Full orange, retro paper texture, blue/purple technology fields and arbitrary per-word colors are rejected.

## Required Extraction

1. 色板、对比度、背景材质和强调色。
2. 字体类别、层级、字重、密度和对齐方式。
3. 组件语法：卡片、边框、图表、纸张、网格、截图框等。
4. 空间结构：连续画板、页面切换、海报、UI、拼贴或其他。
5. 动效线索：镜头、入场、聚焦、路径、转场和节奏。
6. 必须保留的特征、可替代特征和禁止直接复制的品牌/内容素材。
