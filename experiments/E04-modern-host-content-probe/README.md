# E04: Modern IP Host content-layer probe

This is a short, silent visual probe. It keeps the approved `modern-ip-host-explainer` base unchanged:

- `#F2DFC7` light-apricot stage
- supplied Q-version host assets in the fixed `host.left` zone
- fixed caption rail and 1920x1080, 16:9, 30fps canvas

Only the right-side `content-world` changes. The probe tests three candidate carriers from
`style-library/motion-library/knowledge-explainer-v1.json`: a bounded tool surface, a code surface,
and a two-state comparison. The content camera never transforms the host or caption rail.

Run from this directory:

```powershell
npm.cmd run check
npm.cmd run snapshot
npm.cmd run render
```

This probe is not the V5 final video and does not change the formal NarrationLock or production MP4.
